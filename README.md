# DevEvent - The Hub for Every Dev Event

DevEvent is a premium, high-performance platform designed for developers to discover and join world-class hackathons, meetups, and conferences. Built with **Next.js 16**, **Tailwind 4**, and **Framer Motion**, it offers a visually stunning and highly interactive user experience.

## ✨ Key Features

- 🚀 **Ultra-Fast Performance**: Leverages the latest Next.js 16 features for rapid loading and smooth transitions.
- 🎨 **Premium Visuals**: High-end design system with glassmorphism, custom gradients, and shader-based background effects (using OGL).
- 🎬 **Fluid Animations**: Sophisticated entry and hover animations powered by Framer Motion.
- 📱 **Fully Responsive**: Meticulously crafted for all screen sizes, from mobile to ultra-wide displays.
- 🔍 **Dynamic Discovery**: Easily explore featured events with a modern, card-based interface.
- 📄 **Detailed Event Insights**: Comprehensive event pages with registration, sharing, and networking details.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Graphics**: OGL (WebGL)
- **Fonts**: Schibsted Grotesk, Martian Mono

## 🚀 Getting Started

1. **Clone and Install**:
```bash
npm install
```

2. **Run Locally**:
```bash
npm run dev
```

3. **Build for Production**:
```bash
npm run build
```

## 🏗️ Architecture

- `app/`: Contains the main application routes and layouts.
- `components/`: Reusable premium UI components.
- `lib/`: Utility functions and shared constants.
- `public/`: Static assets including icons and images.
